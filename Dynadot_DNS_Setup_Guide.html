🌐 Dynadot DNS Setup & Live Hosting Guide

ஆஞ்சநேயா போர்வெல்ஸ் (anjaneyaborewells.com) இணையதளத்தை Dynadot-ல் இருந்து GitHub-ல் இணைக்கும் எளிய கையேடு

Target Domain: anjaneyaborewells.com GitHub Repo: maniraja5599/AnjaneyaBorewells

1 Dynadot இணையதளத்தில் DNS Records அமைக்கும் முறை (Dynadot Settings)

  1. Dynadot Account-ல் Log in செய்யவும்: www.dynadot.com-க்குச் சென்று உங்கள் Username / Password கொண்டு உள்நுழையவும்.
  2. இடது பக்க மெனுவில் "My Domains" ➡️ "Manage Domains" கிளிக் செய்யவும்.
  3. உங்கள் Domain பட்டியலில் உள்ள anjaneyaborewells.com-ஐ கிளிக் செய்யவும்.
  4. "DNS Settings" பகுதியில் "Dynadot DNS" என்பதைத் தேர்ந்தெடுக்கவும்.
  5. கீழே உள்ள அட்டவணையில் உள்ள 4 A Records மற்றும் 1 CNAME Record-ஐ சேர்க்கவும்:

A) Domain Record (Root Domain - @ / Apex):

Record Type Host / Subdomain IP Address / Target Host (Copy this) TTL
A @ (or Leave Blank) 185.199.108.153 300 / 1/2 Hour / Auto
A @ (or Leave Blank) 185.199.109.153 300 / 1/2 Hour / Auto
A @ (or Leave Blank) 185.199.110.153 300 / 1/2 Hour / Auto
A @ (or Leave Blank) 185.199.111.153 300 / 1/2 Hour / Auto

B) Subdomain Record (www):

Record Type Subdomain Target Host (Copy this) TTL
CNAME www maniraja5599.github.io 300 / 1/2 Hour / Auto

6. அனைத்து Records-ஐயும் உள்ளிட்ட பிறகு, பக்கத்தின் கீழே உள்ள "Save DNS" பட்டனைக் கிளிக் செய்யவும்.

2 GitHub பக்கத்தில் சரிபார்க்க வேண்டியவை (GitHub Pages Settings)

  1. உங்கள் GitHub Repository பக்கத்திற்குச் செல்லவும்: github.com/maniraja5599/AnjaneyaBorewells
  2. மேலே உள்ள Settings ➡️ இடது பக்க மெனுவில் Pages என்பதைத் திறக்கவும்.
  3. Branch: main மற்றும் /(root) தேர்வு செய்யப்பட்டு Save ஆகியுள்ளதா என உறுதி செய்யவும்.
  4. Custom Domain: anjaneyaborewells.com என இருப்பதை உறுதி செய்யவும் (ஏற்கெனவே CNAME File சேர்க்கப்பட்டுள்ளது).
  5. Enforce HTTPS: DNS இணைந்த பிறகு இந்த Checkbox-ஐ Tick செய்யவும் (இலவச Green SSL Padlock கிடைக்கும்).
⏱️ நேரலை எப்போது இயங்கும் (DNS Propagation Time)?
Dynadot-ல் Save DNS கொடுத்த 15 முதல் 30 நிமிடங்களில் DNS முழுமையாக update ஆகிவிடும். அதன் பிறகு https://anjaneyaborewells.com மற்றும் https://www.anjaneyaborewells.com ஆகிய இரண்டு முகவரிகளிலும் உங்கள் இணையதளம் உலகளவில் வேகமாகத் திறக்கும்!
